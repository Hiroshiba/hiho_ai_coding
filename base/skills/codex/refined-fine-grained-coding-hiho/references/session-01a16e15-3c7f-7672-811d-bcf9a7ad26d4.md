## 採用する判断基準

「型と関数を、使われ方と周囲の粒度に合わせる」の、短い式を一行にまとめる規則を局所的に補強する。
式の内部の改行と、処理のまとまりを分ける空行を別々に判断し、目的が変わる境目を同種の既存関数と照合する。
不要なコードを削除する要求を、行数や空行の削減へ置き換えず、差分の前後を読んで各まとまりが見えるか確認する。

読みやすさを保つことは、ログ454・582行の明示的な指摘に根拠があり、証拠があってそうすべきである。
例示した境目を照合する手順への一般化は、そうすべきだと思うという判断である。すべてのループやreturnの前へ空行を入れる固定規約にはしない。
短い式を一行にまとめる既存規則、フォーマッターの制約、CSSの関心事ごとの区切りは維持する。
